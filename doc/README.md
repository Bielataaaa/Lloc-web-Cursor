# Lloc Web de Ciberseguretat

## Descripció Original
En aquest lloc web, el que s'explicarà serà *informació* sobre la ciberseguretat i els tipus de problemes que hi han...
Les funcions que farà la web, seran les bàsiques, com tenir un banner el qual tingui 3 apartats, un home, about us i contact.
També una *funció* just abaix de la *pàgina* on *posi* tota la informacio sense que *faci* falta donar-li al boto de about us i on també puguis suscribirte

Aquest lloc web és una plataforma educativa dedicada a la **ciberseguretat**. Proporciona informació completa sobre els principals riscos de seguretat en línia, tipus de ciberatacs, mesures de p[...]

## Objectiu
L'objectiu principal del projecte és crear una **plataforma web accessible i informativa** que permeti als usuaris:
- Aprendre sobre ciberseguretat de manera clara i ordenada
- Comprendre els principals tipus de problemes i riscos de seguretat
- Accedir a informació estructurada sense necessitat de navegació complexa
- Mantenir-se informats mitjançant una subscripció a novetats

## Com accedir a la web

| Mètode | Enllaç / acció |
|--------|----------------|
| **Enllaç local** (amb servidor actiu) | [http://localhost:8080](http://localhost:8080) |
| **Inici ràpid** | Doble clic a `iniciar-web.bat` (obre el navegador i engega el servidor) |
| **Accés directe** | Doble clic a `CyberGuard.url` (cal que el servidor estigui en marxa; usa `iniciar-web.bat` abans) |

1. Obre una terminal a la carpeta del projecte i executa: `node server.js`
2. O fes doble clic a **`iniciar-web.bat`**
3. Entra al navegador amb: **http://localhost:8080**

Pots desar aquest enllaç als marcadors del navegador per obrir-lo quan vulguis (sempre que abans hagis executat `iniciar-web.bat` o `node server.js`).
